## A little about me

I'm Jeff. Online and in games, I usually go by **Enkiel**; **njinco** is the username I use here on GitHub. I work on network automation, monitoring, self-hosted services, and web apps—from firewall utilities and Linux scripts to publishing tools and Discord bots. I also adapt open-source projects to fit my own workflows.

Away from the terminal, I'm into gaming, photography, diving, and FPV. My projects bring together the systems I manage, the communities I spend time in, and the things I enjoy creating.

## Highlights from my work

- **Network operations:** Tools for Palo Alto firewall backups, configuration audit reports, log filters, and PAN-OS vulnerability tracking.
- **Monitoring and reliability:** Device check-in dashboards, uptime alerts, and a cloud-instance monitor with guarded recovery actions.
- **Publishing and knowledge:** A Markdown writing workspace, feed-reposting automation, a wiki/blog, and an Obsidian sync plugin derived from open-source components.
- **Community tools:** Discord automation, a marketplace browser, gaming reference material, and data-export utilities.
- **Self-hosting:** File-sharing forks, Docker deployments, backup scripts, and utilities for keeping Windows and Linux systems manageable.

# Publish your GitHub profile README

1. Use the public repository **njinco/njinco**. Create it if it does not already exist.
2. Review the bio and work overview in `README.md`, then upload it to the repository root and commit it to the default branch. You do not need to upload this setup guide.
3. Visit https://github.com/njinco to see the profile README. Future edits to the file update the profile.

The work overview was informed by local project READMEs and source files. The profile summarizes areas of interest and work rather than listing individual repositories.

The social hub URL is confirmed by its local source and README. Live availability could not be verified from this environment.

The custom profile README is separate from GitHub's built-in achievement badges and contribution graph.

Official instructions: [Managing your profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).
